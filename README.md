# iota-hub

A Python client library and command-line tool for the [IOTA Hub](https://iota-hub.com)
public API v1 — create an occultation observation draft, upload its files, run the
observer checks, fix or dismiss findings, submit, and query events and observations
with a personal API key.

Docs coming. Until then, see the API's own
[workflow guide](https://iota-hub.com/developers) and
[`docs/client-conventions.md`](docs/client-conventions.md) in this repository.
